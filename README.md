# DevTrack - Developer Attendance & Hourly Rate Tracker

An in-house attendance, time tracking, and hourly rate payroll management dashboard designed for **Diverse Ideas GMBH**.

## 🚀 Key Features
- **Developer Punch Terminal**: Clock in, clock out, and break timer with live wage calculations.
- **Smart Work Mode**: Automatic defaults for **🏠 Work From Home (Mondays)** and **🏢 Onsite Office (Tuesdays–Fridays)**.
- **Live Attendance Board**: Real-time team roster status overview.
- **Timesheets & Automated Payroll**: Aggregates billable hours, rates, project allocations, and gross earnings with 1-click **CSV Export** and **Printable Invoices**.
- **Team & Rates Management**: Multi-currency support (USD $, PHP ₱, EUR €, GBP £) with custom hourly rates per developer.
- **Data Persistence & Backups**: LocalStorage data persistence with 1-click JSON backup & restore.

## 🛠️ Tech Stack
- HTML5, Vanilla CSS3 (Glassmorphic Theme, Dark/Light mode)
- Modern JavaScript (ES6 Modules)
- Firebase Hosting / GitHub Pages Ready

## 📦 Deployment
This app can be deployed to **Firebase Hosting**, **GitHub Pages**, or run locally with:
```bash
node server.js
```
